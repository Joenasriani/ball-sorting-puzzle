# Ball Sort 3D

**Alternate title:** Sorting Balls 3D  
**Status:** original 3D browser logic puzzle  
**Play:** https://joenasr.itch.io/ball-sort-3d  
**Creator:** Joe Nasr  
**Creator identity:** https://joe-nasr-signals.vercel.app/v2/

Ball Sort 3D is a color sorting puzzle where players move the top ball between tubes until every tube contains a single matching color.

## Rules

A ball can move into an empty tube or onto a ball of the same color. The puzzle is solved when all colors are grouped correctly.

The game contains progressive levels, undo, restart, sound controls, desktop input and touch input.

**Ball Sort 3D** and **Sorting Balls 3D** are the same game lineage. They must not be counted as two separate games.

Existing branches and historical files are retained as development history.
